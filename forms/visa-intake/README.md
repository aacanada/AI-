## 설치 (한 번만)

1. 폼 편집 화면 → 오른쪽 위 ⋮ → **스크립트 편집기**
2. `build_form.gs` 내용을 전부 붙여넣고 저장
3. 위쪽 함수 목록에서 `buildVisaForm` 선택 → **실행** → 권한 허용
4. 실행 로그에 폼 링크와 응답 시트 링크가 나옵니다

기존 질문이 있으면 "비자 신청정보 (백업 …)" 사본을 만든 뒤 지우고 새로 구성합니다.
다시 실행하면 응답 시트가 새로 하나 더 생기니 한 번만 실행하세요.

## 신청서 작성할 때

응답 시트 **「IMM 매핑」 탭**에 폼 질문마다 IMM1294 / IMM5708 / IMM5709의 몇 번 문항에
들어가는지 정리돼 있습니다(`—` = 그 신청서에는 없는 항목). 고객 응답 한 줄을 보고
해당 신청서 열의 번호대로 옮겨 적으면 됩니다.

## 폼에 없는 것

- 서류 파일 업로드: 스크립트로 만들 수 없는 항목이라, 필요하면 폼 편집 화면에서
  "파일 업로드" 질문을 직접 추가하세요(응답자는 구글 로그인이 필요해집니다).
- 주민등록번호: 기존 요청서와 같이 폼에서 받지 않습니다.
