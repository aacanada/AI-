## 공개 전 확인

- SLI: 전원 IB인지, 입학 시험 유무, 현재 교장(2026-27 학교운영위원회 명단은 Jamie Allan), 2026-27 시간표
- SLI 학생 수: 출처마다 367~500명. 카드는 브로슈어의 "약 400명" 사용
- 세인트 존스: 교감 이름(페이지마다 다름)은 문서에 넣지 않음. 데이케어 시간 확인
- 세인트 존스 같은 건물 ACCESS 센터에서 어떤 과정(영어·직업)을 여는지 확인 후 블로그 문구 보강
