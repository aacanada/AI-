- 부셔빌 영어 85%/불어 15% (2021 방문 기준)
- 윌리엄 래터 수업 시간(9:10~15:45로 다른 학교보다 늦음)과 증축 일정
- 시더 스트리트 데이케어 시간(2026 공지와 다름), 교장 성
- 19번째 초등학교 확인 (조사로 18곳만 확인)
