# 1차 발행 묶음: 교육청 공통 + 굿셰퍼드 초등학교

> 학교 사진이 없는 조건에서 만든 1차분입니다. 사진 대신 **인포그래픽 카드**(1080×1350, 인스타·카페·블로그 공용)를 직접 만들었습니다. 사진이 생기면 카드 앞뒤에 끼워 넣으면 됩니다.

## 발행 순서 (한 주 안에)

1. **홈페이지**: `homepage/` HTML 두 개를 올립니다. 홈페이지 편집기에는 `<body>` 안의 내용을 붙여 넣고, 대표 이미지는 카드 PNG를 업로드해 주소를 바꿉니다. 올린 뒤 **페이지 주소 2개를 확보**합니다.
2. **블로그 1편 → 2편**: 글 안의 `[이미지: …]` 자리에 카드를 넣고, `[홈페이지 링크]`를 1번 주소로 바꿉니다. 2편의 `[블로그 1편 링크]`도 바꿉니다.
3. **카페 2개**: 블로그·홈페이지 주소를 넣어 올립니다. 카드 3~5장 첨부.
4. **인스타·카톡 채널**: 카드 묶음(캐러셀)으로 그대로 올립니다. 공통 5장 / 굿셰퍼드 5장.
5. 카톡 상담 때는 홈페이지 굿셰퍼드 페이지 주소를 보냅니다.

## 사진 대신 쓸 수 있는 것 (현장 촬영 없이)

- **카페 옛 사진**: AA 몬트리올 카페에 예전 학교 방문 사진이 있으면, 원본을 GitHub 저장소 `plans/riverside-schools/photos/학교명/`에 웹 업로드해 주세요. 카드 배경과 블로그 본문에 넣어 다시 만들겠습니다. (이 환경에서는 네이버 카페에 접속할 수 없습니다.)
- **카페 회원 사진·후기 모으기**: 카페 게시글 ②에 "예전에 다녔던 가족분들 경험 나눠 주세요" 문구를 넣었습니다. 사진을 받을 때는 **사용 동의**를 함께 받습니다.
- **RISE에 사진 요청**: 마케팅 플랜 메일 초안(사진·영상 사용 허락)을 보내면 브로슈어 사진과 학교 영상을 쓸 수 있습니다.
- **학교 유튜브 영상**: 고등학교 4곳 영상 링크는 지금도 블로그에 링크로 넣을 수 있습니다(재편집은 허락 후).

## 카드 다시 만들기

```bash
cd plans/riverside-schools
node tools/render.mjs tools/batch01.html content/batch01/cards
# 전역 playwright를 못 찾으면: PLAYWRIGHT_MODULE=/opt/node-tools/node_modules/playwright/index.js node tools/render.mjs ...
```
- 카드 내용은 `tools/batch01.html`, 디자인은 `tools/cards.css`에서 고칩니다. 폰트는 `tools/fonts/` (Pretendard, OFL 라이선스).
- 홈페이지 HTML: `python3 tools/md2html.py <학교.md> <출력.html> <대표이미지>` (markdown 패키지 필요). 학교 정본 `.md`를 고친 뒤 다시 만듭니다.
