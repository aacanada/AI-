# 리버사이드 학교 정보: 운영 가이드 (내부용)

> 이 폴더의 학교 문서는 **홈페이지에 그대로 올리는 정본**입니다. 이 README는 내부용(공개 금지)으로, 콘텐츠 운영 순서, 학교별 파생 콘텐츠, 사진 확보, 공개 전 확인 목록을 담았습니다.
> 마케팅 전체 플랜은 [`../riverside-marketing/`](../riverside-marketing/README.md)에 있습니다.

---

## 1. 운영 원칙: 홈페이지가 정본, 나머지는 파생

```
① 홈페이지 학교 페이지 (정본: 표, 벨타임, 프로그램, 출처)
        │  매년 8월 갱신. 숫자는 여기서만 고친다.
        ▼
② 네이버 블로그 (이야기: "이런 아이에게 맞는 이유", 방문기, 비교)
        │  본문 끝에 "공식 학교 정보 → 홈페이지 링크"
        ▼
③ 몬트리올 카페 (요약 3줄 + 사진 3~5장 + 블로그·홈페이지 링크 + 질문 유도)
        ▼
④ 숏폼·릴스 (훅 1개 + 숫자 1개 → 프로필 링크)
        ▼
⑤ 카톡 상담 (학교 페이지 링크를 그대로 보냄)
```

- **숫자(벨타임, 학생 수, 비용)는 홈페이지에만 정확히 쓰고**, 블로그·카페에는 "2026-27 기준" 표기와 함께 핵심만 옮깁니다. 바뀌면 홈페이지만 고치고 블로그에는 링크로 안내합니다.
- 학교 문서의 "AA Canada 코멘트"는 홈페이지에 그대로 둬도 되는 톤으로 썼습니다.
- 카페는 네이버 표 붙여넣기가 불안정하므로, 표 대신 **"■ 항목: 내용"** 줄 형식으로 옮깁니다(아래 3장 예시).

## 4. 사진 확보 계획

| 우선 | 방법 | 비고 |
|---|---|---|
| 1 | **몬트리올 지점 직접 촬영** | 가장 확실하고 저작권 문제 없음. 학교 외관·간판·운동장·주변 거리(공공장소에서 촬영). 학생 얼굴은 찍지 않음. 등하교 시간(벨타임 표 참고)을 피해서 |
| 2 | **RISE에 요청** | 브로슈어 사진, 학교 영상 원본, 학교별 사진 사용 허락 (`../riverside-marketing/README.md` 8장 메일에 포함) |

| 4 | 위키미디어 커먼즈 | 위키백과 문서가 있는 학교(Heritage, Centennial, SLI, St. Lambert Elem, GPI, Terry Fox, St. Johns). 라이선스(CC BY 등) 표기 조건 지켜서 |
| 5 | 뉴스 사진 | 해롤드 내퍼 증축(Courrier du Sud, FM103.3), 아고라 몬트리올 포럼 공사 사진. **저작권 있음, 링크로만** |

**촬영 체크리스트 (학교당 6~10장)**: 정문·간판 / 건물 전경 / 운동장·체육 시설 / 주변 주택가 / 가까운 공원·도서관 / (가능하면) 통학버스 정류장 / 근처 장보기(마트)

## 6. 이번 조사의 한계 (다음 조사 때 보완)

- 이 클라우드 환경은 **rsb.qc.ca, 학교 사이트, 레딧, X, 유튜브, 위키백과에 직접 접속이 막혀** 있었습니다. 모든 정보는 웹 검색 결과 요약에서 가져왔고 출처 URL을 붙였습니다.
- 세션당 웹 검색 한도(200회)가 소진되어 **학부모 여론(레딧·X·구글 리뷰), 한인 커뮤니티 정보, 생활 정보(REM 통근 시간, 렌트, 한인 마트), 사진 출처**는 조사하지 못했습니다. 근거 없는 여론은 학교 문서에 쓰지 않았습니다.
- 환경 설정에서 아래 도메인을 허용하면 다음 세션에서 학교 사이트를 직접 읽고 사진 목록까지 만들 수 있습니다: `rsb.qc.ca`, `hrhs.rsb.qc.ca`, `crhs.rsb.qc.ca`, `saintlambertinternational.org`, `reddit.com`, `wikipedia.org`, `upload.wikimedia.org`, `commons.wikimedia.org`, `ibo.org`, `fraserinstitute.org`, `compareschoolrankings.org`
