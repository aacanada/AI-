### 모션 방향 (2026-10-19 원장님 요청: 하이퍼프레임즈 적극 활용, 얼굴 없는 영상)

| 효과 | 구현 힌트 |
|---|---|
| 장면 전환 | 셰이더 전환(`@hyperframes/shader-transitions` / 카탈로그: zoom-blur, flash-through-white, light-leak, glitch 계열)을 **장면마다 다르게** 0.4~0.6초 |

| 키네틱 타이포 | 학교 이름·후크는 글자 단위 split, rotateX 90→0 + y 60→0 + blur 12→0, stagger 0.03. 핵심 숫자는 scale 2.4→1 "슬램" + 카메라 셰이크(3~4프레임) + 원형 쇼크웨이브 |
| 숫자 | 오도미터 롤링 카운터(700, 1,100, $38,000,000, 600ha 등) |
| 지도 | SVG 선 그리기(stroke-dashoffset)로 버논·호수 윤곽 → 핀 낙하 + 글로우 펄스 |
| 칩·배지 | 팝 + 바운스, 체크마크 선 그리기, 도장(scale 3→1, rotate -12°) |
| 파티클 | 후크 슬램과 CTA에서만 골드 파티클 버스트(장면당 최대 120개), 배경에 느린 보케 |
| 배경 | 네이비 메시 그라디언트가 천천히 흐름 + 그리드 패럴랭스, 학교 포인트 색 라이트 릭 |

### 나레이션 음성 (2026-10-19 추가)

- 원장님이 나레이션을 직접 녹음하기로 했다(일레븐랩스 한도 소진, 10/25 복구를 기다리지 않음). 녹음 파일은 장면별 `short-N_sK.m4a`(예: `short-1_s1.m4a` ~ `short-1_s7.m4a`, 6편은 s1~s8)로 들어오며, Aside가 `plans/vernon-schools-shorts/audio/`에 올리고 알려준다. 녹음이 오기 전에는 **음성 없이 만들 수 있는 것을 전부 먼저** 만든다: 공통 템플릿, 6편의 장면·자막 컴포지션(임시 타이밍: 청크당 글자 수 × 0.13초 내외로 추정), 썸네일 6장, upload-text 6개, meta.txt 초안. 무음 미리보기 렌더는 하지 않는다(토큰·시간 절약).
- 녹음이 오면: ffmpeg로 앞뒤 무음 트림(silenceremove), 라우드니스 평준화(loudnorm I=-16), 가벼운 노이즈 제거(afftdn) 후 wav로 변환 → 장면 사이 0.35초 간격으로 이어 `narration.wav` → 장면별 파일 길이로 장면 구간을 잡고, 자막 청크 시작/끝은 글자 수 비율로 나눈다(가능하면 whisper 같은 강제 정렬로 더 정확하게) → `timing.json`을 만들어 렌더. 녹음이 대본과 조금 다르면 자막은 **녹음에 맞춰** 고친다(숫자·사실은 바꾸지 않음). 파일이 빠지거나 잡음이 심하면 멈추고 보고.
- 다른 TTS(HeyGen, Kokoro 등)로 대체하지 않는다.
- 비용 표현: 관리형 비용에 학비가 포함되므로 학비 단독 금액은 어디에도 쓰지 않는다(이번 대본에는 비용 자체가 없음).
