## 1. 핵심 메시지와 표현 수위 (중요)

- 메시지: **부모님이 대학·컬리지가 아니라 사설 어학원만 다녀도, 노바스코샤 학생비자가 있으면 동반 자녀는 공립학교 무상.**
- 근거: 핼리팩스 교육청(HRCE) International Students 페이지, Category I. 부모가 노바스코샤용으로 발급된 유효한 Work Permit 또는 Study Permit을 갖고 있으면 그 기간 동안 자녀 수업료를 받지 않음. 학교 종류(공립대/사립/어학원) 조건은 없음. 이 경우가 아니면 1년 학비 CAD $10,000.
- "아무 조건 없이"라고 단정하지 않는다. 화면/나레이션은 **"대학 안 다녀도"**, **"학교 종류 조건 없음"**으로 표현하고, 각주를 작게 넣는다:
  `* 부모 학생비자(노바스코샤) 유효 기간 기준 · HRCE Category I · 정책은 변경될 수 있음`
- "100% 보장", "무조건" 같은 표현은 쓰지 않는다.

## 2. 모션 그래픽 방향: "최대한 화려하게, 그래도 읽히게"

전체를 **키네틱 타이포 + 3D 카드 + 파티클 + 셰이더 전환** 조합으로 간다. 결과물은 결정적(deterministic)이어야 하므로 모든 랜덤은 시드 고정.

| 효과 | 구현 힌트 |
|---|---|
| 장면 전환 | `@hyperframes/shader-transitions` / 카탈로그(`npx hyperframes catalog`)에서 flash-through-white, glitch, zoom-blur 계열. 장면마다 다른 전환, 0.4~0.6초 |
| 키네틱 타이포 | 글자 단위 split, rotateX 90→0 + y 60→0 + blur 12→0, stagger 0.03. 핵심 숫자는 scale 2.4→1 "슬램" + 카메라 셰이크(3~4프레임, 8px) |
| 임팩트 링 | 숫자 슬램 순간 원형 쇼크웨이브(SVG circle stroke, scale 0→3, opacity 1→0) |
| 파티클 | 캔버스 골드 파티클 버스트(시드 고정 PRNG), 배경에는 느리게 떠다니는 보케 점 |
| 라이트 스윕 | 카드/숫자 위로 45° 반사광 그라디언트가 지나감 (mask + translateX) |
| 3D 카드 | 학생비자·입학허가서 카드: perspective 1600px, rotateY -90→0 플립, 그림자 동시 이동 |
| 도장(스탬프) | scale 3→1 + rotate -12°, 착지 순간 미세 먼지 파티클 + 짧은 셰이크 |
| 숫자 카운터 | 오도미터 롤링(자리수별 세로 스크롤): 40→50, $15,200→$11,400 |
| 선 그리기 | SVG stroke-dashoffset: 캐나다 지도 윤곽, 체크마크, 시계 바늘, 등대 실루엣 |
| 배경 | 네이비 그라디언트가 천천히 흐르는 메시 + 그리드 패럴랙스(배경/중경/전경 속도 다르게) |
| 오디오 | BGM: 밝고 경쾌한 업비트(로열티 프리, `/media-use`), 나레이션 구간 자동 덕킹(`/hyperframes-audio` voiceover carve). SFX: whoosh(전환), impact(숫자 슬램), stamp(도장), cash-register 'ding'(가격), pop(체크). SFX는 과하지 않게 -12dB 내외 |

> 렌더 부담: 파티클 수는 장면당 최대 120개, WebGL 셰이더 전환은 장면 사이에만 사용. 소유자 노트북 렌더가 느리므로 블러 필터 중첩은 최소화.

## 3. 대본 + 장면 설계 (script.json 기준)

자막은 한 줄 13~16자. `chunks: [[자막, TTS발음]]`. 숫자·약어는 TTS에서 한글 발음.

### S1 후크 (0~5초)
- chunks:
  - ["부모가 어학원만 다녀도", "부모가 어학원만 다녀도"]
  - ["아이 학비가 0원?", "아이 학비가 영 원?"]
- 비주얼: 첫 프레임부터 바로 보이는 큰 가격표 **"$10,000 / 1년"**(작게 "핼리팩스 공립학교 유학생 학비"). 첫 청크 끝에 빨간 사선이 가격을 긋고, 두 번째 청크에서 **"$0"**이 3D 슬램(쇼크웨이브 + 골드 파티클 버스트 + 셰이크).
- 첫 프레임이 빈 화면이면 안 됨 (가격표는 0초에 이미 화면에 있음).

### S2 규칙 (5~15초)
- chunks:
  - ["캐나다 노바스코샤주 핼리팩스", "캐나다 노바스코샤주 핼리팩스"]

  - ["자녀 공립학교가 무상이에요", "자녀 공립학교가 무상이에요"]
- 비주얼: 캐나다 지도 윤곽 선 그리기 → 동쪽 끝 노바스코샤로 카메라 줌인, 핀이 떨어지며 "HALIFAX" 글로우. 두 번째 청크에서 **STUDY PERMIT** 카드가 3D 플립으로 등장. 세 번째 청크에서 학교 아이콘에 불이 켜지며 그린 **"FREE"** 도장.

### S3 대학 안 다녀도 (15~25초)
- chunks:
  - ["대학이나 컬리지에", "대학이나 컬리지에"]
  - ["다닐 필요가 없어요", "다닐 필요가 없어요"]
  - ["사설 어학원도 OK!", "사설 어학원도 오케이!"]
  - ["학교 종류 조건이 없거든요", "학교 종류 조건이 없거든요"]
- 비주얼: 왼쪽 "대학 · 컬리지" 카드, 오른쪽 "사설 어학원" 카드가 나란히. 처음엔 어학원 카드가 회색 물음표 → 세 번째 청크에서 그린 체크가 선 그리기로 그려지고 카드가 컬러로 '점등'(라이트 스윕). 마지막 청크에서 두 카드 위로 큰 도장 **"학교 종류 조건 없음"**.

### S4 핵심 트릭: 40주 → 50주 (25~37초)
- chunks:
  - ["핵심은 40주 학비로", "핵심은 사십 주 학비로"]
  - ["50주 입학허가서!", "오십 주 입학허가서!"]

  - ["이걸로 약 1년 학생비자 진행", "이걸로 약 일 년 학생비자 진행"]
- 비주얼: 10×5 주(週) 그리드. 첫 청크에서 네이비 블록 40개가 물결처럼 채워짐(stagger 0.015). 두 번째 청크에서 골드 블록 10개가 위에서 떨어져 끼워지고 카운터가 **40 → 50** 롤링 + 슬램. 세 번째 청크에서 골드 블록 위에 "방학 · $0" 라벨. 네 번째 청크에서 그리드가 접히며 **입학허가서(LOA) 문서 카드**로 변신 → "50 WEEKS" 도장 → 그 아래 "9월~6월 학교 1년" 가로 막대가 꽉 차며 체크.
