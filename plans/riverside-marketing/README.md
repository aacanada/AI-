## 1. 전체 전략 한 줄

**"몬트리올 = 불어라서 안 된다"는 오해를 Riverside로 깬다.**
Riverside는 몬트리올 남쪽 생활권(사우스쇼어, Montérégie)의 **영어 공립 교육청**이고, 슬로건이 *"Réussir dans les deux langues! / Success in both languages!"*입니다. 영어로 공부하면서 불어는 덤으로 익히는 구조라서, 원장님이 평소 권하는 **불어 활용 영주권 루트**와도 바로 이어집니다.

| | 조기유학 (Youth) | 직업학교 (VT) |
|---|---|---|
| 타깃 | 초3~고2 자녀를 둔 30~40대 부모 (엄마 의사결정 비중 큼) | 25~45세 커리어 전환·이민 희망자, 가족 단위 이민 희망 부모 |
| 핵심 약속 | 퀘벡 1위권 영어 공립 교육청 + IB + 홈스테이·가디언 일괄 | 공립 교육청 직업 과정(DEP) → 졸업 후 취업비자(PGWP) 가능 과정 → 영주권 설계 |
| 대표 상품 | 1년 / 한 학기(5개월) / 2~4개월 단기 | 회계·사무, 헬스케어, 자동차·중장비 정비, 보일러(Stationary Engine) 등 12개 과정 |
| 연결 상품 | 엄마 동반 → 사립컬리지·직업학교 + 자녀무상교육 상담 | 부모 DEP + 자녀 RSB 영어 공립학교 (같은 교육청 안에서) |

두 플랜은 **"가족 단위"에서 만납니다.** 조기유학 상담에서 "엄마도 같이 가서 공부하면?"이 나오면 VT 플랜으로, VT 상담에서 "아이 학교는?"이 나오면 Youth 플랜으로 넘깁니다(6장 통합 운영 참고).

## 3. 학교 영상 활용법

### 3-1. 먼저 확인할 점: 동영상 파일은 첨부되지 않았습니다

메일 용량이 16MB로 커서 영상이 첨부된 것처럼 보이지만, 실제 첨부는 **PDF 6개와 서명 이미지**입니다. 영상은 **유튜브 링크 4개**로 왔습니다.

| 학교 | 링크 | 어느 플랜에 쓸지 |
|---|---|---|
| Heritage Regional High School | https://www.youtube.com/watch?v=gzy96ug2B78 | Youth: 예체능, 스포츠, IB MYP, 컴퓨터(iCan) |
| Centennial Regional High School | https://www.youtube.com/watch?v=8XS1q64VHfg | Youth: 영재반(TaG), 이과·인문 |
| Saint-Lambert International High School | https://www.youtube.com/watch?v=iM-vcEJFJ2E | Youth: IB 디플로마 지향, 교복, 소규모 |
| St. Johns School | https://www.youtube.com/watch?v=U39O3cAoE00 | Youth: 초·중·고 한 학교, 형제·남매 동반 |

그 밖에 RISE 인스타그램 [@rise.rsb](https://www.instagram.com/rise.rsb/)과 GUS 프로그램 프로필(https://gus.globaleyes.ca/programs/agency/22/riverside-international-student-education)도 쓸 수 있다고 했습니다.

> 이 작업 환경에서는 유튜브에 접속할 수 없어서 영상 내용(길이, 장면, 자막 유무)은 확인하지 못했습니다. 원장님이 한 번 보시고 **장면별 타임스탬프 메모**(예: `1:20 체육관`, `2:05 과학실`)를 남겨 주시면, 아래 블로그·롱폼·숏폼 구성에 바로 넣겠습니다.
> 직업학교(VT) 영상은 받지 못했습니다. RISE에 따로 요청합니다(8장).

### 3-2. 허락 없이 지금 바로 할 수 있는 것 (링크·임베드 공유)

학교가 "학생과 가족에게 Riverside를 소개할 때 써도 된다"고 준 링크이므로, **원본 그대로 공유**하는 방식은 지금 바로 할 수 있습니다.

1. **네이버 블로그**: 학교별 포스팅 본문 중간에 유튜브 링크 삽입(링크 카드로 표시). 바로 위에 원장님 한 줄 코멘트와 "이 영상에서 볼 장면" 타임스탬프 3~5개를 한국어로 붙입니다. 영상을 끝까지 보지 않아도 학교 분위기가 전달되게 하고, 체류시간을 늘리는 효과도 있습니다.
2. **AA Canada 유튜브 재생목록** `몬트리올 영어 공립학교 투어 | Riverside`: 학교 영상 4개 + AA Canada 롱폼을 한 재생목록에 넣습니다. 남의 공개 영상을 내 재생목록에 넣는 것은 유튜브 기본 기능입니다. 롱폼 설명란과 고정 댓글에 이 재생목록을 연결합니다.
3. **상담 후속 카톡**: 상담 직후 아이 성향에 맞는 학교 영상 1개 + 한 줄 설명을 보냅니다.
   예: "운동 좋아하는 ○○이에게는 Heritage를 먼저 추천드려요. 영상 1:20부터 체육관이 나옵니다."
4. **설명회(웨비나)**: 학교 소개 파트에서 영상을 화면 공유로 틀고, 원장님이 실시간으로 한국어 해설을 합니다. 녹화본은 공개 업로드하지 말고 신청자에게만 보냅니다.
5. **유튜브 "클립" 기능**: 원본 영상에서 5~60초 구간을 클립으로 만들어 링크로 공유합니다(원본 조회수로 집계, 재편집 아님). 카페·카톡에서 "30초만 보세요"용으로 씁니다.
6. **자체 홈페이지(aacanada.co.kr)**: Riverside 소개 페이지에 iframe으로 임베드합니다.

### 3-3. RISE 서면 허락을 받은 뒤 할 수 있는 것 (재편집)

다운로드, 자르기, 한국어 자막 입히기, 내 영상의 배경 화면(B-roll)으로 쓰기는 **저작권자(RSB) 허락**이 필요합니다. 허락과 원본 파일을 받으면 아래를 만듭니다.

| 콘텐츠 | 구성 | 제작 방법 (이 저장소 파이프라인) |
|---|---|---|
| 숏폼 4편 `30초 학교 투어` | 학교별 하이라이트 20~30초 + 한국어 자막 + 마지막 3초 CTA | `/embedded-captions` 또는 `/talking-head-recut`, 9:16 리프레임은 `/media-use` |
| 롱폼 B-roll | "4개 고등학교 비교" 편에서 학교별 30~60초를 배경으로 깔고 원장님 나레이션 | 기존 롱폼 파이프라인(SGA·Olds와 같은 방식), `/hyperframes` |
| 롱폼 오프닝 훅 | 영상 속 가장 인상적인 장면 5초 → "여기가 불어권 몬트리올이라고요?" | `/hyperframes-keyframes` 펀치인 |
| 인스타 릴스·캐러셀 | 영상 캡처 컷 + 학비·일정 카드 | `/motion-graphics` |
| 블로그 GIF | 3~5초 루프(교실, 복도, 체육관) | ffmpeg |

허락 메일 초안은 8장에 있습니다. 허락을 받기 전에는 3-2 방식만 씁니다. 화면 녹화로 몰래 따서 쓰지 않습니다(학교와의 관계, 유튜브 저작권 신고 위험).

## 6. 통합 운영 방법

### 6-1. 원 소스 멀티 유즈 (콘텐츠 1개 → 6곳)

매주 **필러 주제 1개**를 정하고 아래 순서로 쪼갭니다.

```
롱폼 대본(원장님 녹음)  ──►  유튜브 롱폼 (8~12분)
        │
        ├─► 네이버 블로그 (대본을 글로 정리 + 표 + 영상 임베드)
        ├─► 숏폼 3편 (롱폼에서 30초 구간 3개 추출)
        ├─► 인스타 캐러셀 1편 (표·숫자 카드)
        ├─► 네이버 카페 요약글 (블로그 링크 + 질문 1개)
        └─► 카톡 채널 소식 / 설명회 홍보 문구
```

### 6-2. 리드 관리 (드라이브 `AA Canada 상담 DB` 시트 활용)

- 시트에 열 3개 추가를 권합니다: `관심상품`(Youth / VT / 가족), `유입채널`(블로그 / 유튜브 / 숏폼 / 카페 / 소개), `Riverside 단계`(관심 → 상담 → 지원 → CAQ → 출국).
- 모든 링크에 유입 표시를 붙입니다. 예: `aacanada.co.kr/riverside?src=yt_longform_01`. 카톡 상담 첫 질문도 "어디서 보고 오셨어요?"로 통일합니다.
- 교차 판매 규칙:
  - Youth 상담에서 부모 동반 의향 → 사립컬리지 / RSB VT + 자녀무상교육 상담으로 연결
  - VT 상담에서 자녀 있음 → Youth 자료(학교 영상, 학비표) 즉시 발송

### 6-3. 성과 지표 (월말 점검)

| 단계 | 지표 | 목표 예시 (첫 달 실적을 보고 조정) |
|---|---|---|
| 노출 | 블로그 조회, 영상 조회, 숏폼 도달 | 블로그 월 3,000, 롱폼 편당 1,000 |
| 관심 | 카톡 친구 추가, 설명회 신청 | 월 40명 |
| 상담 | 상담 DB 신규 행 | 월 20건 (Youth 12, VT 8) |
| 전환 | 지원서 제출, 등록비 납부 | 월 3~5건 |

## 7. 표현 규칙 (모든 콘텐츠 공통, 꼭 지킬 것)

1. **커미션 정보는 절대 공개하지 않습니다.** Agent 전용 PDF 2개(커미션 14% 표기)는 내부용입니다. 학생에게는 학생용 PDF만 보냅니다.
2. Youth 국제학생은 **학비를 냅니다.** "무상교육"이라는 말은 부모 비자 상태에 따른 별도 상담 주제로만 씁니다. Riverside 조기유학 콘텐츠에 "무상"이라고 쓰지 않습니다.
3. 학비는 항상 **"2027-28 기준(Youth) / 2026-27 기준(VT), 캐나다 달러, 변경될 수 있음"** 각주를 붙입니다.

7. 학교 공식 홍보물처럼 보이지 않게 **"AA Canada 정리"** 톤을 유지합니다. RSB 로고는 작게만 씁니다.
