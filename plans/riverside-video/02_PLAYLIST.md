## 3. 만드는 방법 (AA Canada 채널 로그인 상태에서, 5분)

1. 첫 번째 학교 영상(Heritage) 링크를 엽니다.
2. 영상 아래 **저장** → **새 재생목록 만들기** → 위 제목 붙여넣기 → 공개 → 만들기.
3. 나머지 3개 영상도 **저장** → 방금 만든 재생목록 체크.
4. 유튜브 스튜디오 → 콘텐츠 → 재생목록 → 이 재생목록 → 연필 아이콘 → 설명 붙여넣기, 정렬 "수동"으로 바꾸고 위 순서대로 끌어서 정리.
5. 채널 홈 탭 → 맞춤설정 → 섹션 추가 → 이 재생목록을 채널 홈에 노출.
