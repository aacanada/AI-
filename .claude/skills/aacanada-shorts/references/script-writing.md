# 원고 → scenes.json 작성법

## 구조

```json
{
  "settings": {
    "voice_name": "네 번째", "speed": 1.12, "model": "eleven_multilingual_v2",
    "gap": 0.2, "tail": 1.2, "bgm_volume": 0.12,
    "brand": "AA CANADA", "topic": "몬트리올 자녀무상교육 클래스"
  },
  "scenes": [
    { "id": "01-hook",
      "tts": "몬트리올에서 이제 자녀 무상교육이 안 된다고요? ... 아닙니다!",
      "captions": [["몬트리올에서 이제", "몬트리올"], ["아닙니다!", "아닙니다"]],
      "cues": [] }
  ]
}
```

- `id`는 `NN-영문` 형태. 템플릿의 `%%S_<id>%%`, `c("<id>", …)`와 정확히 같아야 한다.
- `topic`은 화면 좌상단 브랜드 아래 작은 회색 글씨(15자 안팎).
- `bgm_prompt`를 settings에 넣으면 음악 프롬프트를 바꿀 수 있다.

## 장면 설계 (교육용)

| 역할 | 길이 | 예 |
| --- | --- | --- |
| 훅: 오해/질문 | 4–6초 | "~가 안 된다고요? 아닙니다!" |
| 정답 / 핵심 메시지 | 7–10초 | "부모가 사설어학원을 다니면 자녀는 무상교육" |
| 포인트 2–4개 | 각 5–14초 | 장점, 조건, 일정, 학비 |
| 심화 / 장기 플랜 | 10–14초 | 로드맵 |
| 대안 / 패스트트랙 | 7–10초 | 조건부 지름길 |
| CTA | 3–5초 | "지금 에이에이 캐나다에 문의하세요!" |

한 장면 = 한 가지 생각. 장면 텍스트가 3문장을 넘으면 나눈다. 전체 60–90초를 목표로 하되, 원문이 짧으면 더 짧게.

## tts 쓰기 규칙 (귀로 듣는 문장)

- 숫자는 한글로: `$17,075` → "만 칠천칠십오 달러", `$8,125` → "팔천백이십오 달러", `$25,200` → "이만 오천이백 달러", `52주` → "오십이 주", `2년 3개월` → "이년 삼개월", `1년` → "일년".
- 시간: `09:00~13:30` → "오전 아홉 시부터 오후 한 시 반까지". `월~금` → "월요일부터 금요일".
- 약어: `LMIA` → "엘엠아이에이", `AA Canada` → "에이에이 캐나다", `PGWP` → "피지더블유피", `CAQ` → "씨에이큐", `CEGEP` → "세젭".
- 말하듯이: 명사 나열 대신 "~하고, ~하고, ~입니다". 질문형 훅, 짧은 문장.
- 원문의 오타는 고친다(예: "서설어학원"→"사설어학원", "왕 연수"→"어학연수").
- 사실(금액, 기간, 조건)은 원문 그대로. 원문에 없는 수치를 만들지 않는다.

## captions 규칙

- `[표시 문구, 앵커]`. 표시 문구는 숫자/영문으로 보기 좋게, 최대 약 18자(한 줄), 길면 두 줄까지 자동 줄바꿈.
- 앵커는 그 자막이 시작될 때 말하는 tts 속 문자열(2–6글자). 같은 장면에서 앞쪽 첫 등장 위치가 쓰이므로 앞에서 이미 나온 단어면 더 긴 앵커로 구분한다.
- 자막은 다음 앵커까지 유지 → 장면의 첫 자막 앵커는 장면 첫 단어로.
- 자막 앵커는 자동으로 애니메이션 cue로도 등록된다. 자막과 다른 시점에 요소를 등장시키고 싶으면 그 앵커를 `cues`에 추가.
