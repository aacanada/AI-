# 모션그래픽 플레이북 (첫 작품에서 검증된 조합)

장면의 역할에 따라 블루프린트를 고르고, 각 Scene 라인에 실제 단어 타이밍(초)을 적는다. 블루프린트와 규칙의 상세 내용은 `hyperframes-animation`의 `blueprints/`와 `rules/`에 있다.

| 장면 역할 | 블루프린트 | 시그니처 모션 (예시) |
|---|---|---|
| 후킹 | `kinetic-type-beats` | 큰 단어가 쾅 → 코발트 취소선 → 같은 자리에서 단어 교체 |
| 문제(부족/과밀) | `overwhelm-surround` | 고정 크기 상자에 점(지원자)들이 쏟아져 넘침 |
| 문제(경쟁/상승) | `dataviz-countup` | 점수 카드 정렬 → 빨간 커트라인이 올라가며 카운트업 |
| 해법 등장 | `dataviz-countup` | 거대 숫자 0→5,000 카운트업(값이 커질수록 글자도 커짐) + 글로우 |
| 메커니즘 비교 | `comparison-split` | 위아래 카드가 반대 기울기로 등장 → ✕/✓ 배지 → 토큰이 이동 |
| 비유 | `comparison-split`(같은 무대) | 긴 줄 vs 전용 창구, 한 사람이 짧은 줄로 이동 |
| 요건 나열 | `grid-card-assemble` | 2×2 카드가 내레이션 단어마다 하나씩 켜짐 |
| 강조 결론 | `dataviz-countup` → zoom-through → `kinetic-beat-slam` | 막대 비교 후 "엄청난 장점"이 쾅 |
| 주의/브레이크 | `titlecard-reveal` | 조용한 카드 한 장(호흡 장면) |
| CTA | `logo-assemble-lockup` | 3단 경로 노드가 연결되다가 AA Canada 로고로 모임 |

## 원칙
- 장면당 인용하는 규칙(rule id)은 2–3개 이하로 한다. 프레임 패킷은 48KB 한도라 많으면 빌드가 실패한다.
- 등장은 내레이션이 그 단어를 말하는 순간에 한다. 처음 25% 안에 모든 걸 띄우지 않는다.
- 통통 튀는(bounce) 움직임은 쓰지 않는다. `power3`로 부드럽게 멈춘다. 멈춘 장면은 그대로 둔다(숨 쉬듯 커졌다 작아지는 움직임 금지).
- 전환은 2–3종만 반복한다(`push-slide UP`, `push-slide LEFT`, `crossfade`, `zoom-through`). 첫 장면은 `cut`으로 시작한다.
- 호흡 장면(정적인 카드)을 1–2개 넣어 리듬을 만든다.
- 색: 숫자·강조는 코발트, 부정·커트라인만 빨강, 긍정 체크 하나만 초록.
