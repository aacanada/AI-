# 컨셉 제안서 템플릿

1단계에서 이 형식으로 채팅에 제안한다. 대표님이 휴대폰으로 읽을 수 있게 짧게 쓰고, 표는 장면 구성 하나만 쓴다.

```markdown
# [쇼츠 컨셉] <영상 제목 후보>

**한 줄 메시지:** <시청자가 가져갈 단 하나의 생각>
**타깃:** <예: 캐나다 영주권을 고민하는 30–40대 한국인 가족>
**길이:** 약 N초 · 장면 N개 · 세로 쇼츠

## 후킹 (첫 3초) — 하나 골라주세요
1. <질문형: "…하죠?">
2. <반전형: "사실 …가 아닙니다">
3. <숫자형: "5,000명. …">

## 장면 구성
| # | 화면 (모션그래픽) | 내레이션 |
|---|---|---|
| 1 | 큰 글자 "점수 경쟁" → 빨간 취소선 → "빠져나오는 법"으로 교체 | 캐나다 주정부 이민, … |
| 2 | 작은 '쿼터' 상자에 지원자 점들이 쏟아져 넘침 | … |
| … | (장면마다 움직이는 그래픽 1개 이상: 카운트업 / 막대 비교 / 다이어그램 / 체크·엑스 / 경로 연결) | … |
| N | 몬트리올 어학연수 → … → 영주권 경로 + AA Canada 로고 + 상담 문의 | … |

## 썸네일
- 취소선(통념): "<…>"
- 메인 문구: "<…*강조*…>"
- 큰 숫자: "<…>"

## 사실관계 (출처 확인)
- ✅ 확인됨: <내용> — <출처>
- ⚠️ 주의 표현: <과장하면 안 되는 부분과 영상 속 처리 방식>

수정할 부분을 알려주시거나, 괜찮으면 "컨펌"이라고 답해주세요.
```

## 작성 요령
- 내레이션은 쇼츠 템포다. 한 장면에 1–3문장, 쉼표로 리듬을 만든다(쉼표 = TTS 호흡 = 모션 큐).
- 숫자는 화면과 내레이션에서 같아야 한다(첫 작품에서 "-2점/-3점" 불일치를 발견해 수정했다).
- 앞쪽 2–3장면에서 "문제"를 보여주고, 중간에서 해법과 메커니즘을, 뒤에서 "엄청난 장점"이라는 감정 포인트와 주의 한 줄, 마지막에 몬트리올/AA Canada CTA를 둔다.
