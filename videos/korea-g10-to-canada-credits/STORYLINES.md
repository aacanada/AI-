# 세 가지 스토리라인 — "한국 고1 수료 → 캐나다 고교 졸업" BC vs 온타리오

공통: 16:9 · 약 2분 30초 · 내레이션 = ElevenLabs "아홉번째 자연톤" · 앞/뒤 = HeyGen 아바타(대표님 얼굴) · 잔잔한 BGM + 블록이 쌓일 때마다 효과음

## A (추천) — 민준이의 학점 블록 쌓기
- 장치/형식: 한 학생의 사례를 끝까지 따라감 + 화면이 둘로 갈라졌다가 하나로 합쳐지는 구성
- 무엇을 보나: 한국 고1을 마친 민준이의 성적표가 반으로 갈라져 왼쪽 BC(밴쿠버), 오른쪽 온타리오(토론토)로 날아갑니다. 양쪽에 '졸업장 틀'이 있고, 학점이 블록처럼 채워짐 — BC는 4학점짜리 블록 20칸(=80학점), 온타리오는 1학점짜리 30칸(=30학점). 한국 고1 성적이 인정 블록(Equivalency/PLAR)으로 먼저 툭 떨어지고, 11학년·12학년 과목 블록이 차례로 채워지며 필수 시험·요건 체크가 찍힙니다.
- 첫 2초: 대표님 아바타 → 컷 → 한국 성적표 한 장이 화면 가득, "고1 수료" 도장이 쾅.
- 비트: 아바타 인트로 → 성적표 분할 → 졸업요건 틀 소개(BC 80 / ON 30) → 고1 학점 인정 → 11학년 → 12학년 → 시험·기타 요건 → 나란히 비교 결론 → 아바타 아웃트로
- 룩: 밝은 회백색 바탕, BC는 숲 초록, 온타리오는 호수 파랑, 강조색(캐나다 빨강)은 화면당 한 곳. 굵은 한글 산세리프(Noto Sans KR Black).
- 사운드: 차분한 피아노 비트, 블록 착지마다 '톡', 도장 '쾅'.

## B — 졸업장까지 가는 지도
- 장치/형식: 한 장의 지도 위를 카메라가 날아감
- 무엇을 보나: 인천에서 출발한 비행기 경로가 캐나다 지도 위에서 두 갈래(밴쿠버/토론토)로 나뉘고, 각 경로의 정거장이 졸업요건(학점, 필수과목, 시험, 봉사시간)입니다. 정거장을 통과할 때마다 경로가 채워집니다.
- 첫 2초: 인천공항 출발 표시와 "고1 마치고, 캐나다로" 문구.
- 비트: 출발 → 갈림길 → BC 경로 정거장들 → 온타리오 경로 정거장들 → 두 경로 도착 비교 → 아웃트로
- 룩: 지도 일러스트, 두 색의 경로선. 사운드: 여행 느낌 어쿠스틱.

## C (대담한 안) — 상담 책상 위의 두 성적표
- 장치/형식: 위에서 내려다본 유학원 상담 책상, 한 화면이 계속 재배치됨(컷 없음)
- 무엇을 보나: 책상 위에 한국 성적표, BC 졸업 체크리스트, 온타리오 체크리스트 서류가 놓이고, 손(애니메이션)이 형광펜으로 인정 과목을 칠하고, 도장을 찍고, 남은 과목을 포스트잇으로 붙입니다. 실제 상담받는 느낌.
- 첫 2초: 책상 위로 성적표가 미끄러져 들어오고 "이 성적표, 캐나다에선 몇 학점?" 포스트잇.
- 룩: 나무 책상, 서류 종이 질감, 형광펜 노랑. 사운드: 종이 넘기는 소리, 형광펜 소리.
